Codec support

A codec is the method used to compress the video. The browser has to understand that method to show the picture. Support varies by browser, operating system and graphics hardware, so the same file can play on one computer and not another.

What this browser says it can play

"Probably" and "maybe" are the browser's own words. A file can still fail if it uses an unusual profile (for example 10-bit or 4:2:2 color).

General browser support

CodecWhere it usually works
H.264 (AVC)All current versions of Chrome, Edge, Firefox, Safari and Opera. Some Linux builds of Chromium and Firefox leave it out for licensing reasons. 10-bit H.264 and H.264 with 4:2:2 or 4:4:4 color (common in anime fan releases and camera footage) are a different story: Firefox and Safari hand H.264 to the operating system's decoder, which often can't play them, while Chrome, Edge and Opera usually decode them on their own.
HEVC (H.265)Safari on macOS and iOS. Chrome and Edge on macOS and Android. On Windows, Chrome and Edge need graphics hardware that can decode HEVC, and Edge also needs Microsoft's HEVC Video Extensions from the Microsoft Store. Firefox 137 or newer when the graphics hardware can decode HEVC. On Linux and ChromeOS only Chrome with working hardware decoding, so it is often missing there.
AV1Chrome, Firefox, Opera and Edge 121 or newer. Safari only on Apple devices with a hardware AV1 decoder (for example Macs with M3 chips or newer, iPhone 15 Pro or newer).
VP9Chrome, Edge, Firefox and Opera. Safari 16 or newer on Mac, and Safari on iPhone and iPad from iOS 17.4. Safari does not support transparency (alpha) in WebM video.

If a file won't play, try a different browser (Chrome and Edge cover the most codecs on Windows, Safari covers HEVC best on a Mac), or check the up-to-date tables at caniuse.com/hevc, caniuse.com/av1, caniuse.com/webm and caniuse.com/mpeg4.
