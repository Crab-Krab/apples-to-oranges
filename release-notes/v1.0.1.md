A fix release for Apples to Oranges 1.0.

**Use it online:** https://crab-krab.github.io/apples-to-oranges/ (already updated)
**Or offline:** download `index.html` below and replace your old copy.

## Fixed

- **Files that don't start at exactly 0 seconds now line up correctly.** Some videos, often MKV files remuxed from DVDs, start a fraction of a frame late. Version 1.0 counted frames from 0 seconds, so for such a file it usually showed the frame *before* the one asked for. It also showed frequent "is showing its frame …, not frame … as asked" warnings, and could pair it one frame off against an encode that starts at 0. The tool now reads when each file's first frame starts and counts from there.
- **The Wipe divider's knob is symmetric.** It was a text character on a see-through circle. The arrows could sit off-centre depending on the font, the video tinted each half differently, and the line could sit between two screen pixels. The knob is now a drawn, opaque, mirror-image shape, and the line, the knob and the picture's split all sit on the same whole pixel.

## Known limitations

Unchanged from 1.0: automated tests run in Chromium only, HDR and 10-bit video are shown at 8 bits, and variable-frame-rate videos have approximate frame numbers.

## Testing

110 automated browser tests, including new ones for late-starting files and the divider knob.
